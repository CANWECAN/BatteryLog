# BatteryLog 0.11.0 — Core and Research together

BatteryLog 0.11.0 combines Core and the first-party Research tools in one free
Apache-2.0 distribution. There is one wheel and one source archive, with optional
CAN and MDF/MF4 backends. No separate Research package or license is required.

## New workflows

- Desktop single-file and folder analysis, recursive batches, cancellation,
  input inspection, per-file results and a built-in synthetic demo.
- Opt-in temporal observations for sustained imbalance, temperature rise,
  load-relative voltage sag, balancing, unloaded current, contactor feedback and
  precharge-current reduction, with explicit missing/censored-data outcomes.
- Offline CAN preparation, recorded replay and source-linked precharge JSON/HTML
  through `batterylog experimental can|precharge|replay`.
- Declared recording coverage, separate from engineering acceptance, plus opt-in
  relative CSV clocks with exact source-origin provenance.
- Opt-in interpretation JSON/HTML bound to the captured source, engineering
  result, declared context and effective settings by exact-byte SHA-256 hashes.
- Source timestamp ordering checked before binary64 rounding, including mapping,
  normalization and streaming chunk boundaries.

Legacy-only analysis retains frozen result-v8; opt-in temporal models use result-v9.
Interpretation does not modify engineering outcomes or establish physical SOC,
faulty parallel-branch location, sensor correctness or cell fault diagnosis.
These claims remain `NOT_EVALUATED`, including when context metadata is complete.

## Install

Download the wheel below and install it in a Python 3.11+ environment:

```sh
python -m pip install ./batterylog-0.11.0-py3-none-any.whl
batterylog --help
batterylog experimental --help
python -m batterylog.desktop
```

For optional backends, install the same wheel with extras:

```sh
python -m pip install './batterylog-0.11.0-py3-none-any.whl[can,mf4]'
```

The desktop requires Python with Tk support. This release provides Python
distributions, without a standalone desktop installer or a PyPI upload.
`SHA256SUMS` covers both attached distributions.

## Verification and limits

Publication requires the complete Linux/Python 3.11–3.14 matrix, native Windows,
real Tk tests, minimum runtime dependencies, optional MF4 jobs and the unchanged
95% Core coverage gate. Both wheel and source archive are installed separately
outside the checkout, including base/CAN/MF4 and interpretation API/CLI checks.
The release job verifies the same run's artifact checksums before publication.

BatteryLog remains a pre-1.0 engineering beta. CAN workflows are offline; replay
does not transmit to a bus. Experimental observations are not calibrated physical
diagnoses. Engineering limits and measurement declarations remain the caller's
responsibility. Hardware/HIL validation and independent field evaluation are
outside this release's qualification.
