## Open release gates

- [ ] Define the measurement contract: canonical signal identity, supported
  numeric representation, physical units, timestamp/alignment assumptions,
  optional-signal availability, and complete-series topology responsibility.
- [ ] Define and implement the common analysis-service entry point for CLI and
  future desktop callers, with one effective configuration and one result
  authority. Preserve the supported Python API behavior or document migration.
- [ ] Resolve the result-consumer semantic-validation decision tracked in
  [#60](https://github.com/CANWECAN/BatteryLog/pull/60),
  [#63](https://github.com/CANWECAN/BatteryLog/pull/63), and
  [#66](https://github.com/CANWECAN/BatteryLog/pull/66). Keep the published v8
  schema frozen; any successor contract must have a distinct version.
- [ ] Validate the agreed workflows with independent expected evidence,
  including real MF4 ingestion and both current polarities. The CORA campaign
  alone does not establish correctness of every engineering rule.
- [ ] Characterize large-log limits for high event counts and representative
  MF4 layouts. Do not infer an end-to-end memory bound from loader chunk size.
- [ ] Complete a fresh integration review and full Linux/Windows/MF4/package
  matrix on the exact candidate commit. Verify both installed artifacts and
  the test corpus shipped in the source distribution.
- [ ] Reconcile documentation, compatibility decisions and release notes with
  the implemented scope before selecting a release version or creating a tag.

## Integration bug hunt: 2026-10-01

Fixed input: draft [PR #99](https://github.com/CANWECAN/BatteryLog/pull/99),
head `dd31ef50b52ac95a8aaf63c6295e4a1491de188c`, tree
`7f747bd23566e9633ac099792904e006a6cfe12e`. Corrections stay on a separate draft
branch, `fix/0.10-integration-hunt`, based on that build.

Three defects were reproduced before changing their runtime paths:

- A retained analysis-error traceback kept streaming generators suspended,
  leaving CSV path readers and MDF contexts open. The common streaming loop now
  closes its iterator in `finally` when it offers `close()`. Ten regressions
  failed on the fixed input, including actual MF4 path/file cases with and
  without plot collection. Caller-owned handles remain open. A separate test
  preserves support for iterators without `close()`.
- Mixed categorical columns bypassed the required-value boolean check, so a
  boolean could become a numeric measurement. Expand categorical values locally
  for that existing check, without changing the measurement frame. Eight
  cell/time cases failed on pandas 2.2 and 3.0 before the two-line correction;
  strict/exclude modes, chunk sizes 1/3 and distinct missing-value evidence now
  pass.
- HTML/JSON partial-write cleanup caught ordinary exceptions but missed
  `KeyboardInterrupt`. Four interrupted-write cases left temporary files on
  the preceding patch. Catch `BaseException` only at the cleanup boundary,
  remove the temporary file and immediately re-raise. Existing destinations
  remain unchanged and interruption is not swallowed.

Local Python 3.12 checks passed 1,045 latest/MF4 tests at 98.54% coverage and
1,014 minimum-base tests with one optional-MF4 skip. The latter uses NumPy 1.26.0,
pandas 2.2.0 and PyYAML 6.0.1; exact Python 3.11/PyYAML 6.0 compatibility remains
the CI minimum-runtime job's responsibility. Format, lint, package-wide types
and wheel/sdist builds passed. The associated draft PR records the exact-head
cross-platform and installed-artifact CI outcome.

Additional diagnostic probes passed in both local dependency environments:
48 CLI/config/service combinations of current polarity, strict/exclude mode,
HTML/no-HTML, bounded/unbounded event gaps and keep/disable/raise overrides;
schema-valid integral-float result fields; and four output context-exit failures
covering HTML/JSON with fresh/existing destinations. Retaining 20 CSV and 10 real
MF4 error tracebacks added 50 file descriptors on the fixed input and zero on
the corrected tree. The 23 new committed tests are the three defect regressions
plus non-closeable iterator compatibility; the
diagnostic sweep does not claim exhaustive coverage or a physical oracle.

Next review: inspect these corrections on their exact successful CI head, then
resolve the remaining contract/consumer acceptance decisions and high-event
report usability gate. Retaining complete event evidence remains required; no
event truncation, new processing framework or desktop GUI is part of this patch.
No main merge, version change, tag or release is authorized by this checkpoint.
