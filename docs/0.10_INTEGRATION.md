## Build additions

- Reconcile unreleased notes with the assembled APIs, contracts and fixes.
- Check CSV path/handle parity through the installed analysis service.
- Check real MF4 service/path/handle parity against the existing public API,
  then validate packaged v8 structure and opt-in semantics before rendering.
- Exercise each installed wheel and sdist first with base dependencies, then
  with its MF4 extra, outside the source checkout. This reuses the existing
  package-check loop rather than adding another build framework.
- Fix the minimum-job finding: pandas 2.2 requires an explicit missing-value
  representation when nullable measurements are converted to a float array.
  Use NaN in the existing classifier, preserving missing versus invalid-boolean
  evidence. Five nullable cases reproduced the failure before the one-line fix.
- Add one Python 3.11 job for the declared minimum runtime set: NumPy 1.26.0,
  pandas 2.2.0 and PyYAML 6.0. The MF4 extra has its own transitive constraints;
  the minimum-base job does not claim to test that extra at those versions.

## Verification and reproduction

Local Python 3.12 verification passed 1,018 tests with the real MF4 backend,
with 98.53% coverage. Format, lint and package-wide type checks passed. Clean
wheel and sdist environments passed `pip check`, CSV service/CLI/report checks,
and installed MF4 service/path/handle/schema checks. Imports were confirmed to
come from the virtual environment, not the checkout.

All seven result-schema artifacts matched the baseline, wheel and sdist byte
for byte. The source distribution retained its complete test corpus and all
32 end-to-end plus six report-stage measurements. Package and citation versions
matched, and the existing release guard rejected the development version
without creating a tag. Current exact-head CI results and artifact identifiers
are recorded in the associated integration PR, not inferred from source-PR CI.

```sh
python -m pip install -e '.[dev,mf4]'
python -m ruff format --check .
python -m ruff check .
python -m mypy --follow-imports=silent --ignore-missing-imports batterylog
python -m pytest -q --cov=batterylog --cov-fail-under=95
python -m build
python scripts/check_sdist_test_fixtures.py dist/batterylog-0.10.0.dev0.tar.gz
```

The Actions package job builds the wheel from the sdist, installs both artifacts
in fresh environments, exercises the base and MF4 installed workflows, and
uploads checked development artifacts with SHA256SUMS. Fetch artifacts from the
specific successful run associated with the integration commit; a matching
version string alone does not identify the build. Nothing is published as a
GitHub release by a pull-request run.
